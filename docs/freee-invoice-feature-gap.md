# freee請求書の機能調査とFinance Core対応

調査日: 2026-08-14

## 参照した公式ページ

- https://www.freee.co.jp/invoice/
- https://www.freee.co.jp/invoice/advance/features/
- https://www.freee.co.jp/invoice/free/

## 公式ページから確認した機能

- フォーム入力による請求書・見積書・納品書などの帳票作成
- 既存フォーマットの再現、CSV/PDF連携、帳票の一括発行
- 取引先ごとのメール送信、Web共有、郵送代行
- 送付ステータスと取引先のダウンロード日時の確認
- 定期請求、合算請求書、テンプレート設定
- メンバー権限管理と承認ワークフロー
- 銀行口座からの入金明細取得、債権管理、入金消込
- 会計システムへの仕訳連携（CSV/API）
- インボイス制度・電子帳簿保存法への対応
- 請求・入金・仕訳登録ステータスの一元管理

## Finance Coreへの反映

既存実装で対応済みのものは、決定論的な税計算、承認前ドラフト、PDF
プレビュー、正式発行時の採番、スナップショット、改変不能なPDF/JSON、
銀行CSVのプレビュー・取込・候補提示・明示的消込、監査ログです。

今回の実装対象は、外部サービスの契約や認証を必要としない次の機能です。

- 帳票種別（請求書、見積書、納品書、発注書、領収書）の共通ドラフト
- 同一請求の再実行を防ぐ一括・定期ドラフト作成
- 請求書検索、期限超過一覧、顧客別・月別の売上／請求／入金集計
- 送付準備キュー、送付ステータス、ダウンロード履歴
- 会計ソフト取込用のPIIを含まない仕訳CSV出力

メール送信、Web共有、郵送代行、銀行API、会計ソフトAPI、モバイルUIは、
認証情報・外部契約・送信先を必要とするため、ローカルの安全なキューと
CSV/API接続境界までを実装し、実接続は別途明示承認されたアダプターで行います。
